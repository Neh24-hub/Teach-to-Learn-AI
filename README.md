# Teach-to-Learn AI — SIH 2026 Localhost Demo

A vibrant SIH presentation prototype with a frontend, secure Node.js backend, OpenAI evaluation, voice input, concept selection, learning metrics, and a local fallback evaluator.

## Run

1. Install Node.js LTS.
2. Open Command Prompt in this folder.
3. Run `npm install`.
4. Copy `.env.example` to `.env`.
5. Add your new OpenAI API key to `.env`.
6. Run `npm start`.
7. Open `http://localhost:3000`.

Never put the OpenAI API key in `public/index.html`.
